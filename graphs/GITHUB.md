# Recomendações sobre o Git Gui e o Git Desktop

## Git Gui 
*Não recomendo muito, poís não é intuitivo. Exitem complicações que não precisa e talvez dificiculte o seu uso, 
comados que podem ser feitos pelo prompt.
É complicado de mais, para vocẽ que está iniciando na programação recomendo que utilize o Git Desktop.*

## Git Desktop ##
*O git desktop é mais intuitivo, contém um tutorial para criar repositórios e editar eles.
Para você poder fazer isso é necessário seguir algumas etapas.*

## Etapa 1 

*Criar uma conta no GitHub.*
